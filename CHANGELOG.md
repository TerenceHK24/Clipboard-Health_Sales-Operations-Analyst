# Changelog

## 3.0.0 — Universal Operations Agent (self-hosted open-source edition)

- Full local Studio UI: Overview, Data Sources, Findings, Integrations, Governance, Activity.
- Schema-adaptive profiles and evidence-backed cross-system discrepancy findings; optional external AI SDK proposals.
- Business-specific resolution rules are **not** hard-coded into universal workflows: proposals reference registered tools, and humans approve the exact plan.
- Persistent encrypted source snapshots, business finding journal and vault when a company-managed master key is configured.
- Company-configurable REST SDK action manifests, generic OAuth/PKCE bootstrap, MCP adapter, per-capability roles/scopes.
- Rich Slack Block Kit review with native double confirmation, details, questions and a persistent approval-to-execution queue.
- Re-evaluation of source snapshot version and live approval policy before external operations; fail closed on uncertain outcomes.
- Expanded synthetic HTTP, permission, encrypted-store, OAuth, queued Slack and browser workflow tests.
- Preserved the original Bellhaven assessment CLI and separate reconciliation business rules.
