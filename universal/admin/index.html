IT Integration Console

Configure connectors, approvals, and tool permissions. No API keys are stored here.

Local
Security boundary

Enter vault:// references to company-managed credentials, not real keys. New connections are unverified until a trusted provider probe succeeds. Everything is tenant scoped.

1. Connections

Map the company's existing provider installation to a named connection.

2. Capability permissions

Only tool capabilities installed and tested by a developer can be enabled.

3. Approvers

Assign the Slack user who can authorize the enabled actions.

4. Test & activate

Click Test on a connection to verify its permissions through a trusted provider-specific probe. Do not enable writes until a sandbox test and read-back check have passed.
