Security principles

01 · Explicit authorization

Discovery is not approval. A selected plan must be confirmed before tools execute.

02 · Least privilege

Actions are disabled by default. Connection state, scopes and reviewer roles are checked again before execution.

03 · Durable audit

Decisions and operation receipts persist. Uncertain writes are blocked, never blindly replayed.

04 · Credential separation

Secrets live in an encrypted vault or the organization's environment, not in source code or AI-generated plans.
